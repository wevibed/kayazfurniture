# KAY’AZ FURNITURE — SHOWROOM + GALLERY DEMO

Independent React + Vite + Three.js prospect demonstration using the existing immersive showroom framework.

## Included
- Kay’az-branded landing page and navigation.
- Interactive 3D house-style showroom with living room, bedroom, dining and kitchen areas.
- Filterable product gallery with 3D category concept previews.
- WhatsApp enquiry links configured for +263 71 965 8283.
- Responsive mobile-first layout and renderer fallback.

## Important content status
This is a prospect demonstration, not a final client-approved catalogue. The included furniture models are generic procedural concepts, not confirmed Kay’az products. No Dirwa client product photographs or GLB assets are reused. Product photographs, exact product designs, names, specifications, prices, finishes, dimensions, delivery terms and availability must be supplied or approved by Kay’az before public launch. No prices are shown.

## Run locally
```bash
npm install
npm run dev
```

Validate concept models and categories:
```bash
npm run check
```

Production build:
```bash
npm run build
npm run preview
```
